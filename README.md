
# Explorata 🌍

> "A wild website to find a good place, tourism is the correct word."

## 📖 Short Description

**Explorata** is a modern web application designed to help users discover tourism destinations ("good places"). Built as a **Progress Membership Project**, it combines a robust backend with a dynamic frontend to facilitate the exploration of tourism spots, offering a user-friendly and fast experience.

---

## 🧐 Project Overview

Explorata is designed to streamline the process of finding tourism destinations. It serves as a bridge between travelers and interesting locations, managing user memberships and content delivery effectively.

### 👥 Roles
The system is designed to support the following roles:

*   **Guest / Public User**: Can visit the landing page, view "About Us" and "Contact Us", and browse publicly available tourism spots.
*   **Member (Registered User)**: Users who have signed up. They gain access to a personal dashboard, profile management, and exclusive features like saving locations.
*   **Admin**: The platform manager responsible for creating new tourism entries (`destinations-create`) and managing the ecosystem.

### 🚀 Key Features
*   **Tourism Discovery**: A search and browse interface to find tourism destinations with detailed views.
*   **Membership System**: Full authentication flow (Login/Register) with specific user dashboards.
*   **Profile Management**: Users can view and edit their profiles.
*   **Responsive Design**: A modern UI built with **React** and **Tailwind CSS**.
*   **RESTful API**: Laravel backend serving data to the React frontend.


---

## 🛠️ Technologies Used

The project utilizes a modern Monolith/Hybrid tech stack:

### Backend
*   **[Laravel 11.x](https://laravel.com/)**: PHP Framework for the core API and application logic.
*   **MySQL**: Relational database for storing user and tourism data.

### Frontend
*   **[React](https://react.dev/)**: JavaScript library for building the interactive user interface.
*   **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework for styling.
*   **[Vite](https://vitejs.dev/)**: Next-generation frontend tooling.
